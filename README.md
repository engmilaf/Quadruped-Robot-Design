# Quadruped Robot Design

## Overview
This project presents the preliminary mechanical design of a quadruped robot. The objective is to develop a simple and practical robotic platform with four legs capable of stable movement.

## Project Contents
- Body and chassis design
- Leg mechanism
- Joints and Degrees of Freedom (DOF)
- Servo motor selection
- Initial static torque calculation
- Stability and Center of Gravity (CoG)
- Proposed diagonal trot gait
- Expected mechanical challenges

## Design Features
- Compact rectangular body
- Reverse knee leg configuration
- 8 Degrees of Freedom (2 DOF per leg)
- High-torque servo motors
- Lightweight structure
- Stable walking mechanism

## Expected Challenges
- Joint backlash
- Motor overheating
- Leg misalignment
- Foot slippage
- Structural stress
- Battery weight distribution
